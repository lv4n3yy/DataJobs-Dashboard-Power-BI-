# DataJobs-Dashboard (Power BI)
Interactive Power BI dashboard analyzing 12K+ data/ML job postings: salaries, trends, global geography, remote work stats. Drill-through from overview to Machine Learning Engineer details.
​

## 🎯 Project Goals
Track 2024 job trends (volume + salary evolution)

Drill-through analysis: Job Title → detailed metrics

Global map: Job distribution (USA, Europe, Asia, Australia)

Key KPIs: Median Salary, Hourly Rate, Remote %, Health Insurance
